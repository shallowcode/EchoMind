## 如何复验

```powershell
python 项目解读与面试指南/_maintain/build_docs.py
python 项目解读与面试指南/_maintain/verify.py
```

维护脚本在本文件夹内；build_docs 根据人工导读与 AST 生成逐行页，verify 根据 coverage.json 检查哈希/行号并复现选定函数。修改源码后应先更新人工分析，再重新生成。

## 能证明和不能证明什么

这些检查支持所写的分支、阈值和边界问题，**通过不是修复了原项目，也不是整套服务测试通过**。未验证真实模型输出、凭据有效性、Redis/Chroma 连接、实际镜像构建、生产性能、费用或公开认证。
复现固定了输入意图以隔离路由公式；真实 LLM 可能返回不同意图，应另用完整 HTTP 链路验证。数据库协议与模型 SDK 在隔离环境中未加载。
